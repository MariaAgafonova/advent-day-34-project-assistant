## Реализация

1. TypeScript + React/Vite; два Workers, D1, DeepSeek. Lockfile с точными версиями.
2. API: создание/восстановление сессии, создание/список тикетов, история, отправка, эскалация, health.
3. Сервер создаёт клиента и тикет. Случайный токен, в D1 только SHA-256; HttpOnly/Secure/SameSite cookie, Origin-защита, валидация JSON, параметризованный SQL, проверка владения во всех маршрутах.
4. Настоящий MCP SDK Client + Streamable HTTP transport; CRM Worker использует MCP SDK Server и `createMcpHandler` из `agents`. Service Binding передаёт доверенные customer/ticket headers и внутренний secret. Аргументы инструментов строго `{}`; модель не выбирает клиента. Инструменты: `get_customer_context`, `get_ticket_context`. API получает контекст для промпта только через MCP.
5. MCP возвращает ограниченную историю, язык, платформу/версию. Неизвестные сведения — `unknown`; `facts: []`, вымышленные error codes и attempted steps не создаются.
6. Отдельный support-корпус, разбиение по разделам с перекрытием, стабильные хеши, пути/заголовки/строки. Индексатор загружает новый снимок, активирует его и удаляет старый; повтор не дублирует записи. Источники ответов сохраняются снимками в сообщениях.
7. DeepSeek расширяет короткий поисковый запрос; D1 FTS5 выполняет реальный поиск. Не более 6 фрагментов / 12000 символов. Произвольного порога релевантности нет. При сбое расширения используется исходный ограниченный запрос.
8. DeepSeek формирует JSON-ответ; Zod проверяет формат, согласованность статуса/эскалации и принадлежность source_ids полученным фрагментам. Промпт защищает правила, учитывает попытки пользователя, не обещает исправлений и сроков.
9. Пользовательское сообщение сохраняется до внешних вызовов. Уникальный client_message_id, повтор без дублей, запрет параллельной генерации в одном тикете, D1 CAS + lease 120 секунд + attempt fencing. Дедлайн 90 секунд; ограниченные повторы временных ошибок. При сбое текст остаётся в истории, есть безопасный retry.
10. Русский адаптивный чат: диалоги, Enter/Shift+Enter, ожидание, ошибки/повтор, источники, восстановление после перезагрузки, кнопка специалиста. Markdown без необработанного HTML. Эскалация сохраняет needs_human; интерфейса оператора нет.
11. Созданы миграция, синтетический seed двух клиентов с авторизацией/уведомлениями, подробные документы, README, команды запуска/деплоя, CI. Старые Python и Day32 review workflows сохранены.
